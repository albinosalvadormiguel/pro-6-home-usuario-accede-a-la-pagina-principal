# Irydium — Web_Criterios

[![E2E Tests (Cucumber + Playwright)](https://github.com/albinosalvadormiguel/pro-6-home-usuario-accede-a-la-pagina-principal/actions/workflows/e2e.yml/badge.svg)](https://github.com/albinosalvadormiguel/pro-6-home-usuario-accede-a-la-pagina-principal/actions/workflows/e2e.yml)

Sitio de criterios y pruebas E2E con Cucumber + Playwright.

## Scripts

- `npm run test:e2e`: ejecuta los tests E2E (Cucumber + Playwright)

## CI

El workflow de GitHub Actions ejecuta E2E en `main` y sube artefactos (trazas y capturas) en caso de fallo.

## Contenido generado

- Home (Variante B) en `src/pages/index.md` y `src/pages/index.jsx`
- Componente hero en `src/components/Hero.jsx`
- Contenido estructurado en `content/home.json`
- SEO básico en `public/robots.txt` y `public/sitemap.json`
